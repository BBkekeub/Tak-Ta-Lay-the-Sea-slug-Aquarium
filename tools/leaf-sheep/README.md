# แกะทะเล — ต้นแบบชุดใบ

เปิดด้วย `node tools/leaf-sheep/serve.mjs` แล้วเข้า http://127.0.0.1:8770/tools/leaf-sheep/index.html

ใช้ลำตัว LOD และตาจาก asset เดิม แทนพุ่มเหงือกด้วยใบเมชทึบ 18/30/42 ใบ ใบละ 16 triangles รวมเป็น geometry เดียว วัสดุเดียว สี vertex ไม่มี alpha texture ใบยึดผิวลำตัวด้วย raycast เฉพาะตอนเปลี่ยนแบบ ไม่ทำทุกเฟรม

จำนวนเริ่มต้น 30 ใบ = 480 triangles เฉพาะใบ ในทดสอบ draw calls รวมลำตัว/ตา/หนวดเป็น 5 ครั้งต่อเฟรม ไม่มี shadow pass รัน `node tools/test-leaf-study.mjs` ตรวจจำนวนใบ หมุนไม่ rebuild และ idle ไม่ render ต่อเนื่อง พร้อมภาพ view-0..3.png; ไม่มี page/shader error ในรอบทดสอบ Chrome

ต้นแบบนี้ไม่มี save หรือการเพิ่ม species ในเกม ใช้ body pose นิ่งเพื่อดูทรงก่อน ใบไหวเป็น shader deformation เบา ๆ ยังไม่ใช่การผูกกระดูกกับแอนิเมชันจริง เมื่อซ่อนหน้า/หลุด viewport หยุดวาด เปิด motion จึงวาดต่อเนื่อง ตัวเลือกรูปทรงสร้าง geometry ใหม่และ dispose ของเก่า

ข้อจำกัด: รูปทรงใบยังเป็น low-poly แบบร่าง หน้าและหนวดใช้ของเดิม ยังไม่ได้วัด FPS บนเครื่องสเปคต่ำหรือทดสอบฝูงในร้าน ไม่อ้างว่าการทำ 1 เมชทำให้ทั้งเกมเร็วขึ้นแล้ว ก่อนรวมเกมต้องผูกใบกับ rig, รองรับยีน/variant และทดสอบ depth กระจกทุกมุม
