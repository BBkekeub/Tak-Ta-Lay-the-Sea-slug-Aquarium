# ปาหิน: หิน หงอน สนาม และคลื่นแกน X — 2026-09-23

- สนามยาวเดิม 150 ซม. กว้าง 20 ซม. ใช้ LANE_H ร่วมกับการห้ามวางของ/อาหาร และตำแหน่งผู้รอแข่ง

- พลัง 175 + 160×แรงหงอน×แรงเล็ง; F/K 2.4×แรงหงอน กติกาฟาวล์ยังอยู่
