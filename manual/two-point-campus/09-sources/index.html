ทากทาเล · คู่มือวิจัย Two Point Campusตรวจหลักฐาน 19 กันยายน 2026 · ยังไม่มีผล benchmark 1,000 คน
Two Point Campus เพื่อพัฒนาเกมทากทาเล01 — หลักฐานจากเกมที่ติดตั้ง02 — ECS, Burst และงานหลายเธรด03 — การเดิน การหาทาง และฝูงคน04 — โมเดล กระดูก และแอนิเมชัน05 — การวาดภาพ Culling, LOD และ Batching06 — หน่วยความจำ Pool และเท็กซ์เจอร์07 — เปรียบเทียบและแผนพัฒนาเกมทากทาเล08 — แผนทดสอบคอมสเปคต่ำ09 — แหล่งข้อมูลและสิ่งที่ยังไม่รู้10 — สิ่งที่นำมาปรับได้ นอกเหนือจากลูกค้า11 — ตรวจงานคงเหลือหลังมีการปรับปรุงบางส่วน11 — ทำอะไรไปแล้ว เหลืออะไร

09 — แหล่งข้อมูลและสิ่งที่ยังไม่รู้

เข้าถึงแหล่งข้อมูลวันที่ 19 กันยายน 2026 เอกสารเอนจินทั่วไปใช้อธิบายกลไก ไม่ใช่หลักฐานว่า Campus เปิดใช้ทุกคุณสมบัติ

แพตช์จากทีม Two Point โดยตรง

Steam Update 10.0 และรายการอัปเดตต่อเนื่อง

โพสต์วันที่ 3 เมษายน 2024 บิลด์ 10.2.144722 ระบุว่าเปิด render jobs และ GPU skinning โดยรายงานว่าทั้งสองร่วมกันลด frame time 10–20% ในการทดสอบของทีม ปรับการซ่อนสิ่งของขนาดเล็กบนจอ ลด transparency ที่ไม่จำเป็นใน VFX แก้ batching ของ wall shader และปรับขนาด/การตั้งค่า texture เพื่อลด memory โดยเฉพาะ Switch/PS4

ค่าที่ทีมรายงานไม่ใช่ผล benchmark บนเครื่องผู้ใช้ และไม่ใช่คำรับรองว่าเกมเราจะเร็วขึ้นเท่ากัน ถ้าเดิมใช้เวลา T แล้วลด 10–20% จะเหลือ 0.9T–0.8T; FPS จึงเพิ่มประมาณ 11–25% เมื่อไม่มีคอขวดอื่น

หน้าเดียวกันมี character-limit toggle ในอัปเดต 10.0 แต่ไม่ได้ยืนยันจากข้อความนี้ว่าทุกเครื่องวาด 1,000 คนเต็มรายละเอียดได้ลื่น

แหล่งแรกเริ่มอื่น

  • Unity: Multiplatform / Two Point Campus — ยืนยันการใช้ Burst, ECS, URP; ลิงก์ case study เดิม /case-study/two-point-campus เปลี่ยนปลายทางเป็นหน้ารวม resources ในวันที่ตรวจ จึงไม่อ้างเนื้อหาลึกจากบทความที่อ่านไม่ได้
  • Super Spline: Two Point Campus — ผู้ร่วมผลิตระบุงาน hand-key animation และ hero rigging ไม่ได้ให้จำนวนกระดูกหรือวิธี render ฝูงคน
  • NVIDIA: Animated Crowd Rendering — ตัวอย่างเทคนิค animation textures, instancing และ LOD ใช้เป็นแนวคิดทางเลือกของเรา
  • Unity: Static batching — กลไกและข้อจำกัด ไม่เท่ากับ GPU skinning หรือ instancing
  • MDN: WebGL best practices — หลักทั่วไปด้าน batching, render resolution และงาน WebGL; ไม่ใช่ benchmark ของเกมเรา
  • Intel: i3-6006U — ยืนยันรุ่น CPU/GPU ของเครื่องฐานที่เสนอ

หลักฐานในโปรเจกต์

  • local-snapshot.json — เวอร์ชัน config hashes assemblies และจำนวนฐานโมเดลเรา
  • metadata-symbols.json — ชื่อที่คัดตามหัวข้อจาก string table พร้อมข้อจำกัด ไม่ใช่ source code ที่ถอดแล้ว
  • collect-evidence.mjs — วิธีอ่านและนับซ้ำ
