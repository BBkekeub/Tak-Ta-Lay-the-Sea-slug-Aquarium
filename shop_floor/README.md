# หน้าร้านทากทะเล — ต้นแบบไอโซเมตริก (แยกไฟล์)

เปิดเล่นด้วยการดับเบิลคลิก **`index.html`** (ต้องเปิดทั้งโฟลเดอร์ ไฟล์อ้างอิงกัน)

## โครงไฟล์ — แก้ตรงไหน แก้ที่ไฟล์ไหน

| ไฟล์ | หน้าที่ | แก้บ่อยไหม |
|------|---------|-----------|
| `index.html` | โครงหน้า + โหลดสคริปต์ตามลำดับ | นาน ๆ ครั้ง |
| `css/style.css` | หน้าตา/สี/เลย์เอาต์ทั้งหมด | แก้เรื่องดีไซน์ |
| `js/config.js` | **ค่าปรับเกมทั้งหมด** — ราคา, ขนาดพื้นที่, ขนาดตู้/ความจุ, ขนาดพื้นในตู้ | ✅ บ่อยสุด |
| `js/shop-floor.js` | หน้าร้าน: ไอโซเมตริก, กล้อง, วาง/ย้าย/เก็บของ, ขยายพื้นที่, ที่พักพิง, HUD | เมื่อแก้ระบบร้าน |
| `js/people.js` | **ลูกค้าเดินดูตู้ในหน้าร้าน** — โมเดลคนวาดด้วยรูปทรง, เดินเข้า/ยืนดู/เดินออก, ปุ่ม 👥 ลูกค้า | เมื่อแก้เรื่องคน |
| `js/tank-view.js` | โหมดในตู้: พื้นเอียง, ทากเดิน, การ์ดยีน | เมื่อแก้ฉากในตู้ |
| `js/main.js` | จุดเริ่มเกม (วางตู้เริ่มต้น ฯลฯ) | นาน ๆ ครั้ง |
| `js/slug-engine.js` | **เอนจินวาดทากจากยีนตัวจริง** (พอร์ตจากเกมผสมพันธุ์ `lab_4`) + อาร์ต | ⛔ ไม่ต้องแตะ |

## ยีน → รูปลักษณ์ (ใช้ระบบเดียวกับเกมหลัก)

ทากในตู้ **ไม่ได้วาดแบบง่าย ๆ** แต่เรียกเอนจินจริง:
`ยีน → SlugEngine.derived() → SlugEngine.slugParts() → SlugEngine.drawSlug()`
ยีน 9 ตัว: `mainC accC len girth gillLen tentLen vigor gillN spotN` คุมสีลำตัว/สีหงอน/ความยาว/ขนาด/จำนวนหงอน/ลายจุด ฯลฯ — คลิกทากในตู้เพื่อดูค่ายีนจริง

## จุดต่อกับระบบผสมพันธุ์
ตอนนี้ "คลังทาก" สร้างด้วยยีนสุ่ม (`makeSlug()` ใน `config.js`)
ให้ต่อของจริงโดยส่งอ็อบเจกต์ยีนจาก roster เข้า `makeSlug(genes)` แทน

## ปุ่มลัด
ลากพื้น = เลื่อนกล้อง · ล้อเมาส์ = ซูม · คลิกตู้ = เข้าไปในตู้ · ปุ่มขวา = เครื่องมือ/ร้าน/ขยายพื้นที่
