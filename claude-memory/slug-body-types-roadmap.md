ผู้เล่นกำหนดลำดับงานออกแบบทากใหม่ (2026-09-25):
1. **แบ่งประเภทตามรูปร่างตัว 3 แบบ** — (1) แบบปัจจุบัน: ดอริด เสื้อคลุม/หมวกใหญ่เป็นริ้ว (2) ตัวอ้วนกลมยาว (3) กระต่ายทะเล (Aplysia: หนวดหูกระต่าย ปีกข้างตัว)
2. แล้วค่อยทำ **หงอนหลายรูปแบบ**
3. แล้วค่อยดู **การเรียงลาย + สีร่อง/สีตัวของแต่ละสายพันธุ์**

ของตกแต่งในตู้: เลิกทำ 3D ถาวรแล้ว ดู [[decor-2d-only]]

ตัดสินใจแล้ว (2026-09-25):
- รูปร่างเป็นยีนใหม่ · **ผสมได้เฉพาะรูปร่างเดียวกัน** (สายพันธุ์แยกชัด)
- แบบ 2 และ 3 **ปลดล็อกจากโต๊ะวิจัย** (สายวิจัยใหม่ สำเร็จแล้วแบบนั้นถึงเริ่มโผล่ในกล่อง)
- **รอรูปจริงก่อนค่อยเริ่มเขียนระบบ** — สเปกรูปอยู่ที่ manual/slug-body-art-spec.md

**Why:** ทากทุกตัวตอนนี้เป็นทรงดอริดแบบเดียว ผู้เล่นอยากให้มีความหลากหลายของสายพันธุ์
**How to apply:** ทำทีละขั้นตามลำดับ ห้ามข้ามไปทำหงอน/ลายก่อนขั้นรูปร่างตัวเสร็จ · อาร์ต 2D ตัวทากเป็น PNG (META.body + ก้านหงอน) และ 3D เป็น GLB เมชเดียว → รูปร่างใหม่ต้องมีอาร์ตใหม่ทั้งสองฝั่ง · กระทบ codex (486 ช่อง = 9×9×6), research, contests, ตลาด
