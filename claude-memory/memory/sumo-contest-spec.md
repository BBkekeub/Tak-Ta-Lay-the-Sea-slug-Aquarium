สเปกที่ผู้เล่นกำหนด 21 ก.ย. 2026 — ทำเสร็จแล้วใน js/slug-sumo.js (ตู้ tank_sumo)

หัวใจ: เอาโค้ดหลบทางเดิมที่ tank-view.js "ชนข้างตัวอื่น → ตัวนั้นเดินตรงตามทิศหัวของมันเอง 2.8 วิ" มาทำเป็นกติกาเกม ผู้เล่นต้องอ่านทิศหัวคู่ต่อสู้แล้วแตะข้างตอนหัวมันชี้ออกนอกวง = มันเดินออกเอง แตะตอนหัวชี้เข้า = ช่วยมันกลับเข้าวง

- 4 ตัวรุมกันในวงเดียว (โครงเดียวกับตู้กินจุ: คำท้า เดิมพัน อันดับ 1–4)
- ชนข้าง = เหยื่อคุมตัวไม่ได้ T วิ · ชนหัว/ท้าย = ดันกันเฉย ๆ · ชนตอนชาร์จ = T ยาวกว่า + แรงดันทันที
- ท่าชาร์จ: ความเร็ว ∝ จำนวนหงอน (gillCount) · ระยะเวลา ∝ ขนาดหงอน (gillLen) · ระหว่างพุ่งเลี้ยวแทบไม่ได้ → หงอนใหญ่พุ่งนานเสี่ยงพุ่งตกเวทีเอง
- ตัวยาว = โดนแตะข้างง่าย (วัดชนจากแกนลำตัวแบบ capsule) แลกกับมวลมากโดนดันไปน้อย · ตัวเล็กเร็ว โดนยาก แต่โดนทีเดียวปลิว
- แพ้เมื่อจุดกึ่งกลางตัวพ้นเส้นวงค้าง 0.4 วิ
- จบแมตช์: 3 นาที ถ้ายังไม่จบ คนที่ตกรอบแล้วแพ้ (เรียงตามลำดับที่ตก) คนที่ยังอยู่ในวง**เสมอกันหมด**
