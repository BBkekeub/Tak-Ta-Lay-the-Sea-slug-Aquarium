ถ้าพรีวิวในเครื่องมือ (เช่นสีย้อมใน Custom.html) ไม่ตรงกับในเกม ผู้ใช้ต้องการให้แก้ตัวย้อม/ตัวเรนเดอร์ของเครื่องมือจนผลออกมาเหมือนเกม ไม่รับข้อเสนอประเภท "ให้ทำรูปใหม่/ลงแสงรูปใหม่" (มองว่าเป็นการหาทางลัด) — "ในเกมก็ใช้เครื่องมือย้อม ไม่ใช่การทำรูป"

**Why:** 2026-09-26 หงอน Oreo ในโต๊ะมีแกนกิ่งขาวแต่ในเกมไม่มี ผมอธิบายว่าเป็นเพราะอาร์ตลงแสงต่างกันและเสนอให้ทำรูปใหม่ ผู้ใช้ไม่พอใจมาก
ต่อมา (วันเดียวกัน) วิธี "จำกัดช่วงตาราง 80%" ทำให้เหงือก Oreo ทึบสีเดียวไม่มีไฮไลต์ ผู้ใช้ทักว่า "โคตรไม่เข้ากัน" กับหงอนแบบ 3 และสั่งให้ลงสีแบบเดียวกับหงอนแบบ 3
**How to apply:** เทียบกับผลในเกมด้วยภาพ/ตัวเลขที่ยีนเดียวกันก่อนสรุป ดูทั้งตำแหน่งสว่าง-มืดไม่ใช่แค่สีเฉลี่ย แล้วแก้ที่ pipeline ของเครื่องมือ · อย่าใช้การตัดช่วงตารางอีก — ตอนนี้ใช้ "ลงแสงแบบหงอนแบบ 3" (relitCrest ใน species-features.js: โปรไฟล์ขอบ→ในของเกม + ผิวละเอียด + จับคู่ฮิสโทแกรม) · ทดสอบกับผังจริงของผู้ใช้ (ผ่าน Claude in Chrome) ไม่ใช่แค่ฉากที่สร้างเอง · ดู [[custom-editor-build]]
